## Description (4000)

Roomate keeps a shared home running smoothly. Everyone in the household sees the same balance, the same shopping list and the same chore rota, so nobody has to keep score.

SPLIT EVERY BILL
• Add an expense once and split it evenly or by custom amounts
• See exactly who owes whom, person by person
• Settle up and attach a photo of the payment as proof
• Track spending by category and month
• Use the currency your household uses

SHOP TOGETHER
• Keep separate lists, like groceries and the hardware store
• Add items in seconds, with quantities and units
• Tick items off as you shop, so everyone knows what is left

SHARE THE CHORES
• Set up rotating chores so turns move on automatically
• See whose turn it is today
• Keep house events like dinners and meetings on a shared calendar

MADE FOR ANY SHARED HOME
• Flatmates, couples, families or students
• Create a household and invite others with a code
• Belong to more than one household and switch between them
• Light and dark mode
• Available in English, German, Spanish, French and Turkish

Roomate is fair and neutral: it shows the numbers, it doesn't take sides.
